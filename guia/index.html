Sketch Digital Analógico LCD Matriz Sensores Robótica

1. El sketch Arduino

Un sketch es el programa que se carga en la placa. Toda estructura mínima tiene dos funciones: setup(), que se ejecuta una sola vez al arrancar, y loop(), que se repite mientras la placa esté encendida.

void setup() {
  pinMode(13, OUTPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(500);
  digitalWrite(13, LOW);
  delay(500);
}
  • pinMode(pin, modo): define si el pin es INPUT, OUTPUT o INPUT_PULLUP.
  • delay(ms): pausa el programa en milisegundos.
  • Serial.begin(9600): abre el puerto serie para el monitor.
  • Serial.print() y Serial.println(): envían datos al monitor; la segunda agrega salto de línea.
Tipos habituales: int para enteros, float para decimales, bool para verdadero/falso y char para caracteres.

2. Electrónica digital

Las señales digitales tienen dos estados: HIGH (nivel alto, cerca de 5 V) y LOW (nivel bajo, 0 V). Con digitalWrite() escribimos una salida; con digitalRead() leemos una entrada.

void setup() {
  pinMode(2, INPUT_PULLUP);
  pinMode(13, OUTPUT);
}

void loop() {
  int boton = digitalRead(2);
  if (boton == 0) {
    digitalWrite(13, HIGH);
  } else {
    digitalWrite(13, LOW);
  }
}
INPUT_PULLUP. Activa una resistencia interna: el pin queda en HIGH cuando el botón está suelto y pasa a LOW al presionarse. Por eso la comparación es con 0.

Para un semáforo con tres LEDs se enciende uno y se apagan los otros dos. Nunca deben quedar dos salidas altas al mismo tiempo si representamos estados excluyentes.

3. Electrónica analógica y PWM

analogRead() lee un voltaje continuo y devuelve un valor entre 0 y 1023 porque el conversor es de 10 bits. map() transforma ese rango a otro más cómodo.

int pot = analogRead(A0);
int brillo = map(pot, 0, 1023, 0, 255);
analogWrite(9, brillo);

analogWrite() no genera un voltaje continuo real: usa PWM, una señal cuadrada con ciclo activo variable. En los pines 3, 5, 6, 9, 10 y 11 de la Uno permite controlar brillo o velocidad.

constrain(valor, minimo, maximo) limita una lectura para que no se salga del rango esperado. Es útil antes de aplicar analogWrite().

4. Pantalla LCD 16x2

Una LCD de 16 columnas y 2 filas muestra caracteres en posiciones fijas. Se inicializa con lcd.begin(16, 2). Las filas se numeran 0 y 1; las columnas, de 0 a 15.

lcd.begin(16, 2);
lcd.print("Hola Arduino");
lcd.setCursor(0, 1);
lcd.print("LCD lista");

lcd.setCursor(columna, fila): primero la columna, después la fila. lcd.clear() borra toda la pantalla y vuelve el cursor a la posición inicial.

En hardware real, el contraste se ajusta con un potenciómetro conectado al pin VO. Si no se ve texto, girá el potenciómetro antes de cambiar el cableado.

5. Matriz LED 8x8

La matriz tiene 64 LEDs organizados en 8 filas y 8 columnas. Cada punto se enciende con coordenadas (x, y), donde x es la columna y y la fila, ambas de 0 a 7.

matriz.clear();
for (int x = 0; x < 8; x = x + 1) {
  matriz.setPoint(x, 3, 1);
  delay(100);
  matriz.clear();
}

Una animación es una sucesión de frames. Cada frame limpia la matriz, dibuja una figura y espera un breve tiempo. Con módulos MAX7219 reales se usa una librería equivalente para enviar los mismos puntos por SPI.

6. Sensores

Un sensor convierte una magnitud física en una señal eléctrica. En Arduino, los sensores analógicos se leen con analogRead() y los digitales con digitalRead().

  • LDR: resistencia que cambia con la luz; da lecturas altas con más iluminación en el simulador.
  • DHT: temperatura y humedad; en el laboratorio se representa como una lectura proporcional en A2.
  • HC-SR04: distancia por ultrasonido; en el simulador se lee como centímetros en A3.

Un umbral es un valor límite: si la lectura lo supera o cae por debajo, se activa una acción. Para reducir ruido se puede promediar varias lecturas:

int suma = 0;
for (int i = 0; i < 3; i = i + 1) {
  suma = suma + analogRead(A3);
}
int promedio = suma / 3;

7. Robótica: servo, motor y estados

Un servo se mueve a una posición angular: servo.write(90) lo coloca en 90°. Un motor con driver se controla con una señal de dirección y una señal PWM de velocidad.

servo.attach(9);
servo.write(45);
motor.write(200);

Un robot sencillo puede describirse con una máquina de estados: cada estado define una acción y una condición para pasar a otro. Por ejemplo: estado 0 = esperar, estado 1 = avanzar. Usar una variable int estado evita encadenar condiciones confusas.

Proyecto integrador: leer un sensor, decidir con un umbral, mostrar el valor en la LCD, mover un servo y avisar con un LED. Ese patrón —entrada, decisión, salida y comunicación— aparece en casi todos los sistemas robóticos.
